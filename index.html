호텔스닷컴 쿠폰 코드 입력 순서

  1. 1
    전용 링크로 호텔스닷컴 접속

    이 페이지의 받기 버튼으로 들어가 예약을 끝낼 때까지 같은 창을 씁니다. 첫 화면 하단 쿠키 설정 창에서 동의를 누르고, 언어는 한국어, 통화는 KRW(원화)인지 확인합니다.

  2. 2
    호텔스닷컴 계정으로 로그인

    로그인해야 회원가가 보이고, 같은 여행에 호텔을 더 잡을 때 여러 호텔 예약 할인도 붙습니다.

  3. 3
    여행지·날짜 검색 후 숙소 선택

    체크아웃 날짜가 코드 투숙 기간 안에 드는지 먼저 봅니다. SUMMER20·SPECIAL10은 2026년 12월 31일, LP08·LP005는 2027년 6월 30일까지입니다.

  4. 4
    객실 요금에서 지금 결제 선택

    같은 객실이라도 숙박 시 결제 요금을 고르면 쿠폰 코드 입력란이 나오지 않습니다.

  5. 5
    쿠폰 적용에서 쿠폰 코드 입력

    결제 페이지 총 요금 아래 쿠폰 또는 Hotels.com 리워드 적용을 열고 쿠폰 코드 입력을 고릅니다. 예를 들어 할인코드: SUMMER20을 붙여 넣고 적용을 누릅니다.

  6. 6
    요금 요약에서 할인 금액 확인

    요금 요약에 쿠폰 할인 줄이 새로 생기고 총 요금이 줄었는지 봅니다. 할인액은 세금·수수료를 뺀 객실 요금에 할인율을 곱한 값입니다.

  7. 7
    결제수단 입력 후 예약 완료

    카드 전용 할인코드를 넣었다면 반드시 그 카드로 결제합니다. 다른 카드로 결제하면 할인이 적용되지 않습니다.

    받기 버튼으로 다시 들어가 같은 창에서 숙소를 고르고 지금 결제 요금을 선택합니다.
  • E2

    유효하지 않은 코드라고 나올 때

    원인
    예약 기간이 끝났거나, 복사할 때 앞뒤 공백이나 소문자가 섞였습니다. SUMMER20·SPECIAL10·LP08·LP005는 2026년 9월 30일 예약분까지입니다.
    해결
    입력란을 비우고 코드를 대문자로 다시 입력합니다. 10월 이후라면 호텔스닷컴 카드 할인 코드로 바꿉니다.
  • E3

    이 숙소에 적용할 수 없다고 나올 때

    원인
    힐튼·메리어트·하얏트·IHG·아코르 계열처럼 호텔스닷컴 쿠폰 코드 제외 목록에 있는 호텔입니다.
    해결
    같은 지역의 독립 호텔로 바꾸거나, 코드 대신 회원가·가을 세일처럼 코드 없이 붙는 호텔스닷컴 쿠폰으로 요금을 낮춥니다.

    원인

    2027년 6월 30일까지 쓰는 LP08(8%)을 넣습니다.
  • E5

    카드 할인코드가 거절될 때

    해결
    PC 웹에서 지역을 미국으로 바꾸고 미국 사이트 계정으로 로그인한 뒤 달러 요금으로 다시 넣습니다.
  • E6

    할인 금액이 생각보다 작을 때

    원인
    할인은 세금·수수료를 뺀 객실 요금에만 붙고, SUMMER20은 최대 50,000원에서 멈춥니다.
    해결
    객실 요금이 50만원을 넘으면 SUMMER20을 지우고 한도 없는 SPECIAL10을 넣습니다.
  • E7

    해결
    쿠키 동의를 누르고 상단 언어 메뉴에서 한국어와 KRW를 고른 뒤 숙소를 다시 선택합니다. 광고 차단 확장 프로그램도 잠시 끕니다.

호텔스닷컴 할인코드 현장결제도 되나요?

되지 않습니다. 객실 요금 목록에서 지금 결제를 골라야 결제 페이지에 쿠폰 코드 입력란이 생깁니다. 숙박 시 결제 요금은 같은 객실이라도 코드 없이 결제됩니다.

호텔스닷컴 할인코드 두 개 같이 쓸 수 있나요?

한 예약에 하나만 들어갑니다. 객실 요금이 50만원 이하면 SUMMER20, 넘으면 SPECIAL10처럼 금액을 보고 하나를 고릅니다.

호텔스닷컴 앱에서도 할인코드가 입력되나요?

앱 결제 화면에도 입력란이 있습니다. 다만 홈 화면의 앱 아이콘으로 바로 열면 전용 링크 접속 기록이 남지 않아 코드가 거절될 수 있고, 마스터카드 코드는 앱 예약이 아예 제외됩니다.

호텔스닷컴 체크카드도 카드 할인 되나요?

KB국민·현대·하나·토스뱅크는 체크카드도 됩니다. 삼성카드 7%는 개인 신용카드 전용이라 체크·법인·선불카드가 빠지고, 하나카드는 법인·선불카드가 빠집니다.

호텔스닷컴 카드 할인이 일반 할인코드보다 싼가요?

9월 30일까지는 대부분 같거나 비쌉니다. 원화 10% 카드는 SPECIAL10과 할인액이 같고, 50만원 이하 예약은 SUMMER20이 더 깎습니다. 카드가 앞서는 경우는 NH농협 zgm.휴가중카드 20~25%, 30만~73만원대의 마스터카드 World 13%, 10월 이후 예약입니다.

호텔스닷컴 달러 결제하면 수수료가 얼마나 붙나요?

결제액의 약 1.2~1.4%입니다. 국제 브랜드 수수료 약 1%에 카드사 해외 이용 수수료가 더해집니다. 달러 결제 10% 카드를 486,000원 결제에 쓰면 약 6,300원이 빠져 실제 할인율이 8.8%로 내려갑니다.

적립되지 않습니다. 일반 할인코드와 카드 전용 할인코드 모두 스탬프에서 빠집니다. 스탬프 1개의 가치는 1박 요금의 약 10%라서 코드 할인이 10%보다 작으면 스탬프 쪽이 이득입니다.

호텔스닷컴 할인코드로 예약한 뒤 날짜를 바꾸면 할인이 유지되나요?

호텔스닷컴 리워드 스탬프는 언제 사라지나요?
